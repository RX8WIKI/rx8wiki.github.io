    Установка#

    Магнитола#

    Время: 1–2 часа

    1. Снимите штатную магнитолу
    2. Подключите ISO-адаптер
    3. Установите новую магнитолу
    4. Проверьте работу

    Динамики#

    Время: 3–4 часа

    1. Снимите дверные карты
    2. Демонтируйте штатные динамики
    3. Установите новые динамики
    4. Подключите провода
    5. Соберите двери

    Усилитель#

    Время: 4–6 часов

    1. Проложите силовой провод от АКБ
    2. Установите предохранитель
    3. Проложите межблочные кабели
    4. Подключите усилитель
    5. Настройте систему

    Сабвуфер#

    Время: 2–4 часа

    1. Установите сабвуфер в багажник
    2. Подключите акустический провод
    3. Подключите питание
    4. Настройте кроссовер

    Настройка#

    Усилитель#

    Параметр Значение
    Gain По уровню сигнала
    LPF 80 Гц (саб), 80 Гц (фронт)
    HPF 80 Гц (фронт), 100 Гц (тыл)
    Bass Boost 0 дБ

    Параметр Значение
    Эквалайзер По вкусу
    Баланс По центру
    Fader Вперёд (фронт)
    Loudness Вкл

    Шумоизоляция для автозвука#

    Двери#

    Слой Материал
    1 Вибропласт Gold
    2 Сплен 3004
    3 Маделин (антискрип)

    Багажник#

    Слой Материал
    1 Вибропласт Gold
    2 Сплен 3008

    Эффект:

    • Улучшение НЧ на 3–5 дБ
    • Устранение резонансов
    • Лучшее звучание сабвуфера
