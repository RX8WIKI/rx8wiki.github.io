    Диагностические коды (DTC)#

    Полный список кодов неисправностей OBD-II для RX-8:

    Код Описание
    P0300 Случайные пропуски зажигания
    P0301–P0304 Пропуски зажигания по цилиндрам
    P0171 Бедная смесь (банк 1)
    P0172 Богатая смесь (банк 1)
    P0420 Низкая эффективность катализатора
