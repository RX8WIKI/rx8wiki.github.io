## Официальная документация

### Руководство пользователя (Owner's Manual)
Официальное руководство по эксплуатации Mazda RX-8. Содержит информацию по:
- Органам управления
- Техническим характеристикам
- Регламентам ТО
- Эксплуатации в различных условиях

📥 [Скачать руководство пользователя (EN)](https://www.mazdausa.com/siteassets/pdf/owners-archives/rx8/2004/2004-rx8-owners-manual.pdf)

### Руководство по ремонту (Service Manual / WSM)
Workshop Service Manual — полное руководство для сервисных центров. Включает:
- Детальные инструкции по ремонту
- Электрические схемы
- Спецификации моментов затяжки
- Диагностические процедуры

📥 [WSM Mazda RX-8 (EN)](https://www.workshop-manuals.com/mazda/rx8/)

### Каталог запчастей (Parts Catalog)
Электронный каталог оригинальных запчастей с номерами и схемами узлов.

🔗 [Mazda Parts Catalog](https://www.mazdaparts.com/)
