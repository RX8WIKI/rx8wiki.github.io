## Пошаговая инструкция

### Подготовка

1. Отключите АКБ
2. Снимите сиденья
3. Снимите обшивку салона
4. Очистите поверхность
5. Обезжирьте поверхность

### Установка виброизоляции

1. Вырежьте материал по размеру
2. Нагрейте материал феном (40–50°C)
3. Приложите к поверхности
4. Прикатайте валиком
5. Проверьте адгезию

### Установка шумоизоляции

1. Вырежьте материал по размеру
2. Приложите к поверхности
3. Прижмите по всей площади
4. Избегайте натяжения

### Установка антискрипа

1. Вырежьте материал по размеру
2. Приклейте на стыки
3. Уплотните зазоры

### Сборка

1. Проверьте все крепления
2. Установите обшивку
3. Установите сиденья
4. Подключите АКБ
