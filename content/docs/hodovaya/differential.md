# Дифференциал Mazda RX-8

Задний дифференциал распределяет крутящий момент между задними колёсами.

---

## Характеристики

| Параметр | Значение |
|----------|----------|
| **Тип** | Гипоидный, LSD (опционально) |
| **Передаточное число** | 4.10 (МКПП), 3.91 (АКПП) |
| **Объём масла** | 1.0–1.2 л |
| **Тип масла** | GL-5 80W-90 |
| **Ресурс** | 200 000+ км |

---

## Типы дифференциалов

### Открытый

| Преимущество | Недостаток |
|--------------|------------|
| Простой | Пробуксовка одного колеса |
| Надёжный | Плохая проходимость |

### LSD (Limited Slip Differential)

| Преимущество | Недостаток |
|--------------|------------|
| Лучшая тяга | Требует спецмасло |
| Меньше пробуксовок | Дороже в обслуживании |

**Типы LSD:**
- **Вискомуфта** — вязкостная муфта
- **Фрикционный** — пакеты фрикционов
- **Червячный** — червячная передача (Torsen)

## Диагностика

### Признаки неисправности

| Симптом | Причина |
|---------|---------|
| Вой при разгоне | Износ главной пары |
| Вой при торможении | Износ подшипников |
| Стук при трогании | Износ шестерён |
| Вибрация | Дисбаланс, износ |
| Течь масла | Износ сальников |
| Пробуксовка одного колеса | Износ LSD |

### Проверка уровня масла

1. Поднимите автомобиль
2. Найдите заливное отверстие
3. Уровень должен быть по краю отверстия
4. При необходимости долейте

### Проверка люфта

1. Поднимите автомобиль
2. Возьмитесь за колесо
3. Покачайте в разные стороны
4. Люфт указывает на износ

### Проверка LSD

1. Поднимите заднюю часть
2. Проверните одно колесо
3. Другое должно вращаться в ту же сторону
4. Если в обратную — LSD не работает

## Замена масла

**Время:** 30–45 минут

### Пошаговая инструкция

1. **Подготовка**
   - Поднимите автомобиль
   - Прогрейте дифференциал (поездка)

2. **Слив масла**
   - Открутите заливное отверстие (сверху!)
   - Открутите сливное отверстие (снизу)
   - Слейте масло
   - Закрутите сливное отверстие

3. **Заправка**
   - Залейте новое масло (1.0–1.2 л)
   - Уровень по край заливного отверстия
   - Закрутите заливное отверстие

4. **Завершение**
   - Проверьте на течь
   - Проедьте 10 км
   - Проверьте уровень

> ⚠️ **Важно:** Сначала открутите заливное отверстие! Иначе можете не залить новое масло.

## Замена сальников

### Входной сальник

**Время:** 60–90 минут

1. Слейте масло
2. Отсоедините карданный вал
3. Открутите фланец
4. Извлеките сальник
5. Установите новый сальник
6. Соберите в обратном порядке
7. Залейте масло

### Сальники полуосей

**Время:** 90–120 минут

1. Слейте масло
2. Снимите полуоси
3. Извлеките сальники
4. Установите новые сальники
5. Установите полуоси
6. Залейте масло

---

## Ремонт дифференциала

### Замена подшипников

**Время:** 3–4 часа

1. Снимите дифференциал
2. Разберите дифференциал
3. Снимите старые подшипники
4. Установите новые подшипники
5. Соберите дифференциал
6. Установите на место

### Замена главной пары

**Время:** 4–6 часов

1. Снимите дифференциал
2. Разберите дифференциал
3. Замените главную пару
4. Настройте пятно контакта
5. Соберите дифференциал
6. Установите на место

> ⚠️ **Важно:** Настройка пятна контакта требует опыта и оборудования!

### Ремонт LSD

**Время:** 4–6 часов

1. Снимите дифференциал
2. Разберите дифференциал
3. Замените фрикционы
4. Соберите дифференциал
5. Установите на место

**Зачем:**

## Тюнинг дифференциала

### LSD

| Тип | Преимущество | Недостаток |
|-----|--------------|------------|
| **Фрикционный** | Предсказуемый | Износ фрикционов |
| **Червячный** | Долговечный | Дорогой |
| **Электронный** | Контролируемый | Очень дорогой |

### Блокировка

- **100% блокировка** — для офф-роуда
- **Частичная блокировка** — для спорта

### Охлаждение

- Установка радиатора
- Увеличение ресурса
- Рекомендуется для трека
