# АКПП Mazda RX-8

RX-8 оснащается 6-ступенчатой автоматической коробкой передач Aisin AW6A-EL.

---

## Характеристики

| Параметр | Значение |
|----------|----------|
| **Модель** | Aisin AW6A-EL |
| **Передачи** | 6 вперед, 1 назад |
| **Тип** | Гидротрансформатор |
| **Объём масла** | 9.5 л (полная), 4.5 л (частичная) |
| **Тип масла** | ATF M-V |
| **Ресурс** | 150 000–200 000 км |

---

## Режимы работы

| Режим | Описание |
|-------|----------|
| **P (Park)** | Парковка, блокировка вала |
| **R (Reverse)** | Задний ход |
| **N (Neutral)** | Нейтраль |
| **D (Drive)** | Автоматическое переключение |
| **M (Manual)** | Ручной режим (+/-) |

## Диагностика

### Признаки неисправности

| Симптом | Причина |
|---------|---------|
| Пинки при переключении | Низкий уровень масла |
| Пробуксовка | Износ фрикционов |
| Задержка включения | Неисправность соленоидов |
| Толчки при переключении | Загрязнение масла |
| Не включается передача | Механическая неисправность |
| Горит индикатор AT | Ошибка АКПП |

### Проверка уровня масла

**На прогретой АКПП:**

1. Запустите двигатель
2. Прогрейте АКПП до 60–70°C
3. Установите автомобиль на ровную поверхность
4. Переведите селектор через все режимы
5. Верните в P
6. Проверьте щуп (если есть)
7. Уровень между MIN и MAX

> ⚠️ **Важно:** На RX-8 может не быть щупа — проверка через сливное отверстие!

### Считывание ошибок

1. Подключите OBD-II сканер
2. Считайте коды АКПП
3. Расшифруйте коды

**Типичные коды:**
| Код | Описание |
|-----|----------|
| **P0700** | Ошибка системы управления АКПП |
| **P0715** | Ошибка датчика оборотов турбины |
| **P0720** | Ошибка датчика оборотов вала |
| **P0750** | Ошибка соленоида A |
| **P0755** | Ошибка соленоида B |

## Замена масла

### Частичная замена

**Время:** 30–45 минут

1. Поднимите автомобиль
2. Открутите сливную пробку
3. Слейте масло (4–5 л)
4. Закрутите пробку
5. Залейте новое масло через заливное отверстие
6. Проверьте уровень

### Полная замена (аппаратная)

**Время:** 60–90 минут

1. Подключите аппарат замены
2. Запустите двигатель
3. Произведите замену (9–10 л)
4. Проверьте уровень

### Замена с фильтром

**Время:** 60–90 минут

1. Поднимите автомобиль
2. Снимите защиту
3. Открутите поддон
4. Замените фильтр
5. Установите поддон (новая прокладка!)
6. Залейте масло

---

## Адаптация АКПП

### После замены масла

1. Запустите двигатель
2. Прогрейте АКПП
3. Переведите селектор через все режимы
4. Проедьте 10–20 км в разных режимах

### Сброс адаптации

1. Подключите сканер
2. Выберите «Сброс адаптации АКПП»
3. Выполните процедуру обучения

## Ремонт АКПП

### Капитальный ремонт

**Когда требуется:**
- Пробег 200 000+ км
- Серьёзные неисправности
- После перегрева

**Что меняется:**
- Фрикционы
- Стальные диски
- Подшипники
- Сальники
- Соленоиды (опционально)

**Стоимость:** $1500–2500

### Замена АКПП

**Новая:** $3000–4000
**Восстановленная:** $2000–3000
**Контрактная:** $1000–1500

- Меняйте масло каждые 60 000 км

- Используйте ручной режим на спусках
