    Турбина и компрессор на Mazda RX-8#

    Форсирование атмосферного двигателя RX-8 — популярный способ увеличения мощности.

    Штатная мощность#

    ПараметрЗначение
    Мощность192 л.с. (141 кВт)
    Крутящий момент216 Нм
    Объём1.3 л (2 ротора)

    Типы форсирования#

    Турбонаддув#

    ПреимуществоНедостаток
    Высокая мощностьТурбояма
    КПД вышеСложнее установка
    Лучше на трассеТребует интеркулер

    Компрессор#

    ПреимуществоНедостаток
    Линейная отдачаМеньший прирост
    Нет турбоямыОтнимает мощность
    Проще установкаШумнее

    Установка#

    Турбо-кит#

    Время: 20–40 часов

    1. Демонтаж впуска/выпуска
    2. Установка коллектора
    3. Установка турбины
    4. Установка интеркулера
    5. Прокладка трубопроводов
    6. Установка топливной системы
    7. Прошивка ЭБУ
    8. Настройка

    Компрессор-кит#

    Время: 15–25 часов

    1. Демонтаж впуска
    2. Установка компрессора
    3. Установка ремня
    4. Прокладка трубопроводов
    5. Установка топливной системы
    6. Прошивка ЭБУ
    7. Настройка

    Рекомендации#

    Для улицы#

    • Буст: 0.4–0.6 бар
    • Мощность: 240–280 л.с.
    • Компрессор предпочтительнее

    Для трека#

    • Буст: 0.7–0.9 бар
    • Мощность: 320–380 л.с.
    • Турбо предпочтительнее

    Для драга#

    • Буст: 1.0+ бар
    • Мощность: 400+ л.с.
    • Усиленный двигатель обязателен
