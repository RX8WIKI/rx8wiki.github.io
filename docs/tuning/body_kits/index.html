    Установка#

    Бампер#

    Время: 4–6 часов

    1. Снимите старый бампер
    2. Примерьте новый бампер
    3. Подгоните зазоры
    4. Закрепите болтами
    5. Покрасьте (если требуется)

    Пороги#

    Время: 3–4 часа

    1. Поднимите автомобиль
    2. Снимите старые пороги
    3. Примерьте новые
    4. Закрепите болтами/клеем
    5. Покрасьте (если требуется)

    Спойлер#

    Время: 2–4 часа

    1. Разметьте отверстия
    2. Просверлите отверстия
    3. Установите крепления
    4. Закрепите спойлер
    5. Загерметизируйте отверстия

    Капот#

    Время: 3–4 часа

    1. Снимите старый капот
    2. Переставьте петли и замок
    3. Установите новый капот
    4. Отрегулируйте зазоры
    5. Установите упоры (карбон)

    Уход#

    Мойка#

    • Мойте мягкой губкой
    • Избегайте мойки под давлением на краях
    • Используйте автошампунь для лака

    Защита#

    • Нанесите воск каждые 3 месяца
    • Используйте керамическое покрытие
    • Избегайте парковки под деревьями
