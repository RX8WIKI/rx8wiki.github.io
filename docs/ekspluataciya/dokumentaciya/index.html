          Диагностические коды (DTC)#

          Полный список кодов неисправностей OBD-II для RX-8:

          КодОписание
          P0300Случайные пропуски зажигания
          P0301–P0304Пропуски зажигания по цилиндрам
          P0171Бедная смесь (банк 1)
          P0172Богатая смесь (банк 1)
          P0420Низкая эффективность катализатора
